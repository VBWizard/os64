Uploads outside the script heap

A speed test's upload: a string of 25 MiB, four Blobs made of it, each sent by an XMLHttpRequest. The string is the page's, but the Blobs' bytes are the page's body bound's (XHR_BYTES.md § 7), so four of them, 100 MiB, fit beside a 64 MiB script heap and the scripts keep running after. Run it with script_memory_mb = 64 in yonder.conf: under the default heap the bytes would fit in the heap either way.

Serve this page over http from a server that answers a POST (yonder, like other browsers, refuses a request for a file: address), for example python3 -c "import http.server as h class S(h.SimpleHTTPRequestHandler): def do_POST(s): n=int(s.headers['Content-Length']);s.rfile.read(n);b=str(n).encode() s.send_response(200);s.send_header('Content-Length',len(b));s.end_headers();s.wfile.write(b) h.ThreadingHTTPServer(('',8000),S).serve_forever()", which answers each upload with the length it received.
