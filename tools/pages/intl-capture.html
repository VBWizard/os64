Intl capture

What this browser's Intl answers for en-US, captured as a file: the strings libjs is held to byte for byte (INTL.md § 8). It formats a fixed matrix of DateTimeFormat cases (option bags, zones, instants, ranges, parts), asks the questions other browsers answer differently (an alias zone's name), and lists the browser's Intl surface.

Open it from tools/intl_capture_server.py, which serves this directory and saves what the page sends to the file it names; or press Save for a download.
