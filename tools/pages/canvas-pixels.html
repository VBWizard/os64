Pixel by Pixel

A drawing that stays put. Pixels you can read, keep, erase, and bring back.

Enable Scripts and Modern Web, then reload to paint the canvases.

1. A fresh coat

The button swaps the palette. Clear squares reveal the canvas background.

2. Keep a little history

An ImageData snapshot brings back the drawing, including its transparent window.

3. The same size, a clean slate

First click assigns the same width and clears it. Next click paints it again.

4. A change of address

The same canvas moves between its two homes. Its pixels come along.

Try 25%–400% zoom. CSS changes the display size; the stored bitmap keeps its pixels.
