crypto.subtle, tier 1

WEB_CRYPTO.md's tier 1: SubtleCrypto and CryptoKey whole, every algorithm normalized, and digest with SHA-1, SHA-256, SHA-384 and SHA-512. Each line below is a check against a published value (FIPS 180-2's example messages) or the behaviour Web Cryptography requires; another browser shows every line PASS, and so should yonder. The checks that want NotSupportedError use a name no browser knows, so they stay true when later tiers add algorithms.
