Intl on the glass

Intl's en-US strings, as Chrome writes them (INTL.md § 8, its capture, and for numbers § 9.6): each row is checked byte for byte, except the German request, which resolves to the only locale os64 holds. Chrome writes an ASCII space where CLDR has a narrow no-break or thin space, in format, parts and ranges alike, and a no-break space between a currency code and its digits. With the Modern Web switch off there is no Intl, and the page says so.
