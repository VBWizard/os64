Intl on the glass

Intl.DateTimeFormat's en-US strings, as Chrome writes them (INTL.md § 8, its capture): each row is checked byte for byte, except the German request, which resolves to the only locale os64 holds. Chrome writes an ASCII space where CLDR has a narrow no-break or thin space, in format, parts and ranges alike. With the Modern Web switch off there is no Intl, and the page says so.
