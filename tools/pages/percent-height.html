Percentage heights

CSS 2.1 § 10.5: a percentage height is of the containing block's height when that height does not wait on the content (a length, a percentage that itself resolved, an absolute box's, and the window's above the root), and is auto when it does. Another browser shows every check PASS, and so should yonder.

height is a percentage. Beside it, a dashed red outline is the height the
blue box should have; the two tops line up, so a blue box that matches its
outline is right. Under each caption, the height the script measured: green
when it is the expected one, red when it is not.
