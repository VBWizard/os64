# specifications: each IN is one declaration, each OUT the longhands it
# sets, `invalid` when the value does not fit its property's grammar, or
# `unknown` for a property libgarb does not read, `held` for a value the
# cascade reads once its var() or env() is replaced. `quirks` before an IN
# reads it as quirks mode does. Run by tools/test_garb_suite.py.
