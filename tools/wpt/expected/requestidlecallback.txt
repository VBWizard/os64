[required]
# P2b: requestIdleCallback, cancelIdleCallback and IdleDeadline. Each fails
# with the switch off. What still fails: callback-timeout-when-busy, whose
# idle callback runs in the 4 ms gaps between a busy page's clamped timers
# (HTML lets an idle period start there; Chromium's come after frames, which
# yonder does not draw on a schedule), and callback-timeout, whose busy loop
# reads Date.now(), which the runner's clock never moves.
